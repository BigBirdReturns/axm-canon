# ASOIAF repository state operator v1

This directory replaces the obsolete operational purpose of the historical `axm-canon-state-refresh-v0.2` patch with a repository-native, read-only state operator. It is a new successor identity. It does not materialize, reproduce, apply, or authenticate the missing state-refresh packet or its patch.

The historical packet was prepared against exact `axm-canon` base commit `fec0ddc9a5697d465ac46e55b7e3cb7647221952`. The repository has since admitted the six-edition public corpus and six continuation successors through governed pull requests. Reapplying the old two-file patch to the current tree would therefore be a category error even if its bytes were recovered. `state.py` derives the exact checkout commit and tree it is inspecting, verifies the seven declared continuation-successor evidence paths, hashes those evidence files, and reports every surviving predecessor and private-integration hold.

The seven successor lanes are released-*Winds*, So Spake Martin descent, multilingual terminology control, multilingual reception, public-source descent, the fail-closed v4.2 recovery operator, and this repository-state operator. Their existence closes the successor-construction queue for the seven continuation-v3 component classes. It does not materialize any of the seven sealed predecessor archives and does not change the continuation-v3 manifest's `payloadMaterialized: false` fields.

The state operator invokes `git` only through fixed argument vectors with `shell=False`. It performs no checkout, reset, fetch, patch application, commit, branch update, remote write, source ingestion, canon promotion, graph mutation, private-estate integration, or v4.2 build. Its output is an observation receipt bound to the exact local commit, tree, and evidence-file hashes. A detached checkout is valid; branch identity is optional while commit and tree identity are mandatory.
