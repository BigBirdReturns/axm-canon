# ASOIAF Source Atlas

`index.html` is a self-contained reader generated from public-safe corpus data. It contains the complete six-edition structure, all 805 candidate evidence routes, the 254-entity concordance, and the first 31-record AGOT opening gate.

It contains no source paragraph text, EPUB bytes, private database, original filename, or holder filesystem path. The exact private edition and paragraph ledgers remain outside Git.

Open `index.html` directly in a browser. The reader requires no server and makes no network request.
