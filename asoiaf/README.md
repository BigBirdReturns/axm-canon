# ASOIAF canon estate

This directory applies the repository's generic canon, continuity, provenance, and closure law to *A Song of Ice and Fire* and its related source families. It is a research estate, not a flat lore database. Every usable object retains source identity, continuity lane, provenance, review standing, and the authority it is permitted to exercise.

## Authority boundary

Model recall, conversation synthesis, fan consensus, adaptation dialogue, licensed companion material, author statements, released future material, and exact book text occupy different evidentiary lanes. None is promoted merely because it has been collected or indexed. The public repository contains public-safe data, schemas, tests, tools, receipts, and derived research surfaces. Holder-controlled book bytes remain outside the repository.

## Repository surfaces

The `src/` tree contains the ASOIAF domain model, recall registry, external-source atlas, reconciliation logic, structured public adapters, and review machinery. The `tools/` tree contains bounded emitters and acquisition operators. The `tests/` tree enforces provenance, source-health, admission, continuity, and public-boundary behavior. The `docs/` tree records the operating contracts and retained receipts.
